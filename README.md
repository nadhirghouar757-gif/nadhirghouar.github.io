# Nadhir Ghouar — Professional Portfolio

A responsive personal portfolio for Nadhir Ghouar, teacher of English and TEFL specialist.

## Publish with GitHub Pages
1. Open the repository Settings.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then Save.
5. After GitHub finishes publishing, the site will be available at https://nadhirghouar757-gif.github.io/.

## Update content
Edit `index.html`, `style.css`, or `script.js`. The portrait is stored in `assets/nadhir-ghouar.jpg`.
